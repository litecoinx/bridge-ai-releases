# Bridge AI

An operations center for supervising a fleet of coding agents.

## Download

**[Download Bridge AI for Mac](https://github.com/litecoinx/bridge-ai-releases/releases/latest/download/Bridge-AI.dmg)**

Apple Silicon Macs only (M1 or newer).

## Install

1. Open `Bridge-AI.dmg` and drag **Bridge AI** into **Applications**.
2. Open **Bridge AI** from Applications. macOS will refuse the first time, because the app isn't signed with an Apple Developer ID.
3. Open **System Settings → Privacy & Security**, scroll down to the message about Bridge AI, and click **Open Anyway**. Confirm once more.

You only do this once. After that the app opens normally.

## Updates

Bridge AI checks for new versions itself and offers **Update now** when one is out. It never updates or restarts on its own, and updating keeps your running terminal sessions alive.

All versions: [Releases](https://github.com/litecoinx/bridge-ai-releases/releases)
